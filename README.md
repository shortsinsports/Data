# Shorts in Sports: Data

**Small data | Big games**

This repository is the home of the data sets for **Shorts in Sports**, a Tableau-based data visualisation community initiative.

## What is Shorts in Sports?

Shorts in Sports shares a small, fun data set from a sporting event and invites the community to show what they see in it. It is designed to be simple, and to work for people who are busy.

A challenge can focus on a single match, a race, a tournament, or one standout performance or moment.

There is no fixed format and there will never be a right answer. You might go minimalist or highly designed. The point is to take a bite-sized data set and make something of it.

Read the launch post: [Chris's blog](https://www.westlakeanalytics.com/blog-posts/blog024.html) / [Rob's blog](https://thedatataylor.com/blog010.html)

## How to take part

1. **Download** the data from this repository (or from Tableau Public).
2. **Create** your visualisation in Tableau.
3. **Publish** it to [Tableau Public](https://public.tableau.com).
4. **Share** it with the community using **#ShortsInSports**.

## Data sets

The data is bite-sized on purpose. Each release lives in this repository.
